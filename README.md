# Tienda Gatos

Tienda online de productos para gatos: areneros, arena y comida premium.

Cliente de ZeroAI para generación y gestión de leads.

## Desarrollo

```bash
npm install
npm run dev
```

Abre `http://localhost:5173`

## Build

```bash
npm run build
```

## Deploy

Conectado a Vercel — deploy automático desde `main`.
